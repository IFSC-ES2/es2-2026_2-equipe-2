# M-04 — Tempo médio de conferência de um pedido

| Campo | Descrição |
|-------|-----------|
| **Nome** | Tempo médio de conferência de um pedido |
| **Classificação** | Produto |
| **Objetivo** | Avaliar se o sistema está tornando o processo de conferência mais rápido em relação ao processo manual/planilha anterior, refletindo diretamente o valor operacional proposto pelo projeto. |
| **Definição / fórmula** | Média de (data/hora em que o status do pedido muda para "concluído" − data/hora em que o status muda para "em andamento"), calculada sobre os pedidos conferidos no período. |
| **Fonte dos dados** | Registros de mudança de status de conferência armazenados no banco de dados do sistema. |
| **Frequência de atualização** | Mensal, a partir do momento em que o módulo de Conferência estiver funcional e em uso simulado/real. |
| **Responsável pelo acompanhamento** | Bernardo Amaral Lisboa (DBA). |
| **Forma de interpretação** | Redução do tempo médio ao longo do uso do sistema é um indicativo de ganho de eficiência operacional. |
