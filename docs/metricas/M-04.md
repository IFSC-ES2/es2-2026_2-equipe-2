# M-04 — Testes unitários automatizados (quantidade e taxa de aprovação)

| Campo                               | Descrição                                                                                                                                                                                                                                                                                 |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Nome**                            | Testes unitários automatizados (quantidade e taxa de aprovação)                                                                                                                                                                                                                           |
| **Classificação**                   | Produto                                                                                                                                                                                                                                                                                   |
| **Objetivo**                        | Avaliar a estabilidade, robustez e qualidade interna do produto a cada incremento, garantindo que as regras de negócio (estoque, clientes, vendas/pedidos) e componentes de interface estejam cobertos e protegidos contra regressões.                                                    |
| **Definição / fórmula**             | Total de testes unitários automatizados implementados e executados com sucesso no backend e frontend: `(Testes aprovados / Total de testes) × 100%`. Acompanha-se tanto o crescimento do volume absoluto de testes quanto a taxa de aprovação (meta de 100%).                             |
| **Fonte dos dados**                 | Relatórios de execução do framework de testes automatizados (Vitest) no backend (`api-estoque`) e frontend (`frontend`), além do workflow de CI (`.github/workflows/test-check.yaml`).                                                                                                    |
| **Frequência de atualização**       | A cada sprint.                                                                                                                                                                                                                                                                            |
| **Responsável pelo acompanhamento** | Victor Eduardo Peixer Munarim (Engenheiro de Qualidade/QA).                                                                                                                                                                                                                               |
| **Forma de interpretação**          | O crescimento consistente do volume de testes a cada sprint indica que as novas funcionalidades estão sendo entregues com garantia de qualidade. A taxa de aprovação deve se manter em 100% nas releases; qualquer teste falhando impede a integração contínua e a entrega do incremento. |
