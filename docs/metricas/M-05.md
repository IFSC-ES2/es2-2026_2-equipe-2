# M-05 — Distribuição de issues concluídas por integrante

| Campo | Descrição |
|-------|-----------|
| **Nome** | Distribuição de issues concluídas por integrante |
| **Classificação** | Projeto |
| **Objetivo** | Garantir que a carga de trabalho está equilibrada entre os cinco integrantes da equipe ao longo do projeto, evitando sobrecarga de uma pessoa específica ou dificuldade recorrente de outra em avançar. Ajuda a decidir se é necessário redistribuir tarefas nas próximas sprints. |
| **Definição / fórmula** | Nº de issues concluídas por cada integrante no período, comparado entre os membros da equipe (pode ser expresso também em percentual do total de issues concluídas na sprint). |
| **Fonte dos dados** | Atribuição de issues (assignee) no board do repositório (GitHub Projects/Issues). |
| **Frequência de atualização** | A cada sprint. |
| **Responsável pelo acompanhamento** | Daniel Luiz da Rocha Cordeiro (Arquiteto de Software). |
| **Forma de interpretação** | Distribuição relativamente equilibrada entre os integrantes é o cenário desejado. Grandes disparidades sustentadas ao longo de várias sprints podem indicar sobrecarga de um integrante ou dificuldade pontual de outro, sendo um ponto a discutir nas retrospectivas da equipe. |
